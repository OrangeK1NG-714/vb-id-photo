# 隐私处理说明

## 处理目的

用户照片只用于本次证件照抠图、换底、克制精修、规格裁切和付费下载，不用于人脸识别、身份比对、模型训练、广告画像或其他用途。

## 保存期限

- 默认在订单创建两小时后删除原本次生成的预览、高清图和排版图。
- 清理任务可重复执行，服务重启后会依据 SQLite 中的创建时间继续清理。
- 订单状态可为售后核对短期保留，但不包含图片二进制；如需设定订单数据期限，应在上线前补充明确政策。

## 安全措施

- 生产环境仅允许 HTTPS。
- 高清图和排版图不在静态目录公开，只有可信支付状态为 `paid` 且下载令牌匹配时才返回。
- 微信支付成功以验签并解密后的服务端通知为准，不采信前端“支付成功”参数。
- `.env`、支付私钥、平台证书、SQLite 和运行时图片禁止提交 Git。

## 第三方处理者

上线前必须在微信小程序隐私保护指引中如实披露所选人像分割服务、云服务器和对象/文件存储服务的名称、用途、数据类型、地区和保存期限。当前代码未绑定某一家供应商，不能用占位厂商提交审核。

## 用户权利

小程序内应提供真实可用的客服/隐私联系渠道，用于查询或申请提前删除。当前仓库不填虚假联系方式；提交审核前由负责人补充真实信息并进行一次删除请求演练。
