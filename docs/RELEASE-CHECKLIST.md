# 上线与提审清单

## 本地代码门槛

- [ ] `cd server && npm run check` 全部通过。
- [ ] `cd server && npm run smoke` 显示尺寸与重启持久化两项通过。
- [ ] 小程序全部 JS 文件通过 `node --check`，微信开发者工具无编译错误。
- [ ] `trial`、`release` 环境填入真实 HTTPS 后端域名，开发 mock 只在 `develop` 使用。
- [ ] 两小时隐私清理、订单过期页和受控下载在测试环境验证。

## 资质和凭证

- [ ] 个体户/企业营业执照。
- [ ] 已认证微信小程序 AppID，并完成服务类目确认。
- [ ] 微信支付商户号、API v3 密钥、商户私钥、证书序列号、平台证书。
- [ ] 已备案/符合微信要求的 HTTPS 域名，并加入 request/downloadFile 合法域名。
- [ ] 已签约的国内人像分割服务及生产密钥，成本已核算。
- [ ] 云服务器与持久卷；如改用 COS/OSS，配置生命周期删除并更新隐私披露。

## 产品和隐私

- [ ] 小程序隐私保护指引披露照片用途、第三方处理者、默认两小时删除和真实联系方式。
- [ ] 页面不承诺“保证过审”；真实照片测试未通过前，只描述“不改变五官”和具体处理能力。
- [ ] 使用真实人像集验证无脸、多人脸、遮挡、横图、头顶贴边、深色背景和高分辨率图片。
- [ ] 对每个高频证件规格核对官方最新尺寸和背景要求，不能只依赖通用名称。

## 真机与支付

- [ ] iOS 与 Android 微信真机完成上传、预览、支付、高清图和排版图保存。
- [ ] 小额真实支付成功，服务端回调验签解密成功，金额/AppID/商户号校验通过。
- [ ] 回调延迟、重复回调、支付取消、服务重启和订单过期均验证。
- [ ] 确认支付前无法访问高清文件，错误令牌返回 403，未支付返回 402。

## 发布动作

- [ ] 负责人确认隐私文本、定价、客服和退款规则。
- [ ] 提交微信审核前关闭所有生产 mock 开关并保存检查证据。
- [ ] 审核通过后由负责人确认发布时间；任何真实发布和收款启用都不由自动化脚本执行。
