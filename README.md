# 证件照精修微信小程序

原生微信小程序 + Node.js 后端。产品只做换底、克制提亮/匀肤和规格裁切，不做瘦脸、大眼或改变五官。是否符合具体报名/证件要求，以对应机构的最新规则为准。

## 当前能力

- SQLite 持久化订单状态：`created`、`paying`、`paid`、`failed`、`expired`。
- 预览与付费文件分目录；高清下载要求服务端可信支付状态和随机令牌。
- 微信支付 V3 请求签名、通知验签、AES-GCM 解密与幂等回调原语。
- 图片真实格式、文件大小、像素上限、规格/底色/精修强度校验。
- 可注入人脸检测；未配置或服务不可用时明确降级，不宣称头部位置已校验。
- 默认两小时隐私清理，服务重启后继续执行。
- 自管理烟测会验证处理、显式 mock 支付、下载尺寸和重启恢复。

## 后端命令

```bash
cd server
npm ci
cp .env.example .env
npm run check
npm run smoke
npm run dev
```

开发 mock 支付只有在 `.env` 明确设置 `ALLOW_MOCK_PAYMENTS=true` 时启用。生产环境禁止 mock，缺少支付、人像分割、HTTPS 地址或强下载密钥时进程会拒绝启动。

## 小程序环境

后端地址在 `miniprogram/config.js` 中按 `develop`、`trial`、`release` 分离。`trial` 和 `release` 默认留空作为发布门禁，提交体验版/正式版前必须填真实 HTTPS 域名。

开发者工具可用 `http://localhost:3000`；真机不能把 `localhost` 当作电脑，应使用同一局域网可访问地址或测试 HTTPS 域名。

## 仍需负责人提供

- 营业执照、已认证小程序和微信支付商户资质。
- 微信支付商户凭证、私钥与平台证书。
- 国内人像分割服务账号和密钥。
- 公网服务器、HTTPS 域名和微信合法域名配置。
- 真实客服/隐私联系方式及提审确认。

这些外部条件未完成前，只能称为“本地上线就绪”，不能真实收款或提交发布。部署、隐私和提审细节见 `docs/`。
